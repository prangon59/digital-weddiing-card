# সাকিব ও ভাবনা — বাংলা স্ক্রল-স্টোরি ওয়েডিং ইনভাইট (`story-invite`)

মোবাইল-ফার্স্ট, সম্পূর্ণ বাংলায় স্ক্রল-নির্ভর ১৩-দৃশ্যের ওয়েডিং ডিজিটাল কার্ড।

## ১. লেখা, তারিখ ও লিংক পরিবর্তন করবেন কীভাবে
সব নাম, বাবা-মায়ের নাম, তারিখ, ভেন্যু, Google Maps লিংক, এবং WhatsApp নম্বর এক জায়গায় রাখা আছে:

- ফাইল: `src/config.js`
- শুধু ওই ফাইলের মানগুলো বদলালেই পুরো সাইটের সব দৃশ্য ও `.ics` ক্যালেন্ডার আপডেট হয়ে যাবে।

## ২. যুগল ছবি (`couple.jpg`) বসানো
- `public/assets/couple.jpg` ফাইলে আপনার পোর্ট্রেট বা স্কোয়ার ছবি রাখুন (প্রস্তাবিত: কমপক্ষে `1200px`)।
- মুখ যেন ফ্রেমের মাঝের ওপরের অংশে থাকে (`object-position: center 25%` সেট করা আছে)।
- WhatsApp/Messenger-এ শেয়ারের প্রিভিউ ছবির জন্য `public/assets/og-share.jpg` (`1200x630`) আপডেট করুন।

## ৩. ব্যাকগ্রাউন্ড মিউজিক (`music.mp3`) পরিবর্তন
- `public/assets/music.mp3` ফাইলটি আপনার পছন্দের কপিরাইট-মুক্ত MP3 দিয়ে প্রতিস্থাপন করুন (২MB-এর কম হলে মোবাইল লোডিং দ্রুত হবে)।

## ৪. লোকালি চালানো ও বিল্ড করা
```bash
npm install
npm run dev
npm run build
```

## ৫. Netlify-তে ডিপ্লয়
1. `npm run build` চালান অথবা Netlify-তে এই `story-invite` ফোল্ডারটি (অথবা Git repo-তে Base directory হিসেবে `story-invite`) সিলেক্ট করুন।
2. Build command: `npm run build`, Publish directory: `dist` (`netlify.toml` আগে থেকেই কনফিগার করা আছে)।
